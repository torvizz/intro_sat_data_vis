# Curso de Visualização, Aquisição e Edição de Dados de Satélite 

Este repositório contém os notebooks do curso para visualização, aquisição e edição de dados de satélite de váriáveis meteoceanográficas, utilizando Jupyter Notebooks em ambiente Google Colab, ministrado no 9° Congresso Brasileiro de Oceanografia em 24 de agosto de 2026, Vitória - ES.

## Como usar

1. Clique no botão **Open in Colab** da aula desejada.
2. No Colab, vá em `Arquivo → Salvar uma cópia no Drive`.
3. Trabalhe sempre na cópia salva no seu Google Drive.
